# Web Refresher: Kyoto Travel Mini-Guide

### Reflection
The development of this single-page travel guide is a structured refresher for foundational web development skills. The structuring of semantic HTML5 tags like `<header>`, `<main>`, `<article>`, `<section>` and setting up CSS Grid for the attraction cards was straightforward and intuitive. 

The main challenge is about making sure layout consistency when adjusting screen sizes in developer tools, specifically managing image aspect ratios and button tap targets across mobile viewports. I have also focused on maintaining accessible button states when toggling the tips container via JavaScript.

During Web Development II, the main skill I want to refine is writing modular, clean JavaScript and understanding state management in depth as we transition from manual DOM manipulation into React components.
